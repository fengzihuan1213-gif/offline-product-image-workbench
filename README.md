# 离线产品图工作台

面向电商产品图片的本地工作台。支持自动抠图、详情长图分段、产品与背景合成、阴影和光线调整，以及产品／背景／文字分层。

首次安装需要联网下载 Python 组件和模型。准备完成后，图像处理在本机 CPU 上运行，浏览器通过 `127.0.0.1` 访问工作台。

## 功能

| 页面 | 功能 |
|---|---|
| 合成工作台 | 自动抠图，擦除／恢复画笔，拖动、缩放和旋转，背景铺满，自动估算光线和接地阴影，PNG 导出 |
| 长图分段 | 按横向留白寻找切点，手动调整切线，连续分段，逐张或 ZIP 导出 |
| 图片分层 | 提取主要产品和检测到的文字区域，透明 PNG 图层，文字识别草稿编辑，图层显示开关和 ZIP 导出 |
| 本地项目 | 保存素材引用、位置参数、图层状态和修改后的文字，重新打开继续编辑 |

## 安装与启动

已在 Windows 10/11、64 位 Python 3.12 环境验证。建议使用 Python 3.12。准备一个现代浏览器即可使用界面。

下载本仓库后，在项目文件夹打开 PowerShell，依次执行下列命令。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\download_models.py
.\start.cmd
```

安装完成后，日常双击 `start.cmd` 即可启动。控制台会显示本机访问地址，浏览器自动打开。

依赖安装中附带 RapidOCR 中文／英文模型。下载脚本另外准备 U²-Net 抠图模型，验证文件长度和 SHA-256。模型与运行环境由用户本地获取，未提交到源码仓库。

Python 安装在 PATH 中且没有 `py` 启动器时，可将第一条命令改为 `python -m venv .venv`，先确认 `python --version` 为 3.12。

其他系统可以尝试以下命令，跨平台运行尚待验证。

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/download_models.py
.venv/bin/python server.py
```

## 使用

### 产品和背景合成

1. 导入产品实拍，执行自动抠图。
2. 放大检查金属高光、玻璃边缘和手柄内孔，用擦除／恢复画笔修正。
3. 导入背景，拖动产品，调整大小和角度。
4. 自动匹配会根据产品落点附近的背景，估算亮度、色温和接地阴影。可以手动微调。
5. 生成合成图后导出 PNG，或保存为本地项目。

### 长图分段

导入长图并设定高度范围，自动寻找版块间留白。预览切线后可以增删或修改。分段覆盖整张原图，保留原图宽度与像素。缺少明确留白时，请检查兜底切线是否穿过文字或产品。

### 图片分层

自动分出主体、背景和检测到的文字区域。原文字以像素图层保留，OCR 草稿可以修改后重新排字。默认背景在遮挡处留透明空洞。勾选背景修补时，程序根据附近像素推测填充。

## 效果范围

- 透明玻璃、镜面金属、细小吊环和复杂背景需要检查边缘。已在锅具样图中观察到吊环内孔残留白底，可用画笔修正。
- 光线匹配依据局部图像统计，阴影是二维近似。镜面反射和真实三维光照无法由此保证一致。
- 默认 OCR 主要识别中文和英文。韩文、艺术字体和模糊小字需要人工校对或另配模型。
- 分层由图像识别估算，原字体、矢量路径和遮挡后内容无法从扁平图片准确找回。修补背景属于推测结果。
- 大图分层的内存开销较大。超出限制的长详情图应先分段，再逐段分层。

## 本地数据与离线运行

| 目录 | 内容 |
|---|---|
| `data/assets/` | 导入图片、抠图与合成结果 |
| `data/projects/` | 保存的项目配置，每次保存产生一个新记录 |
| `data/exports/` | 导出的 PNG 和 ZIP |
| `models/` | 本地抠图模型 |
| `.venv/` | Python 运行组件与 OCR 模型 |

程序绑定本机回环地址，页面与字体资源来自本地。服务进程限制外部 socket 连接，缺少模型时会显示状态或降级使用白底识别。页面底部的退出按钮可以结束服务，关闭页面后服务会继续运行。

可以在另一台联网电脑准备完整运行环境和模型，再部署到离线电脑。Python 虚拟环境通常与 Python 安装路径和系统相关，迁移到新电脑时建议重新安装依赖。

## 开发

图像处理位于 `engine.py`，本地服务位于 `server.py`，界面位于 `static/`，首次模型准备脚本位于 `scripts/`。

```powershell
.\.venv\Scripts\python.exe -B server.py --no-browser --port 8788
```

`--data` 可以指定本地项目和导出目录。`--port 0` 由系统分配空闲端口。
